# Enterprise Banking Application

## Overview

This project is a Java 17 Spring Boot banking application developed as a DevOps implementation project.

The application provides REST APIs for customer management, account management, deposits, withdrawals, balance checking, and transaction history.

## Technologies

### Application
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate

### Database
- PostgreSQL

- CloudFormation

- Grafana

## Application Features

- Customer creation
- Account creation
- Deposit money
- Withdraw money
- Balance checking
- Transaction history
- Application health monitoring
